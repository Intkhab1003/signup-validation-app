# Premium SaaS Signup & Form Validation App

A visually stunning, portfolio-ready form validation application built for Webora Tec (Week 3, Task 2). This project demonstrates modern UI/UX design patterns, 3D interactive elements, and robust client-side validation using strictly Vanilla technologies.

## 🚀 Features
- **Modern UI/UX Design:** Dark mode "Midnight Aurora" theme with glassmorphism and animated gradient orbs.
- **Client-Side Validation:** Real-time feedback for Name, Email, and Password fields using custom Regex.
- **Interactive 3D Tilt:** Mouse-tracking 3D effect on the form card (desktop only).
- **Password Strength Meter:** Calculates strength based on length, caps, numbers, and special characters.
- **Accessibility (a11y):** Semantic HTML, ARIA live regions for error reading, and accessible input labels.
- **Mock Success State:** Simulates a network request with a loader, then swaps to a success UI without claiming a real backend creation.

## 🛠️ Technologies Used
- HTML5 (Semantic Structure)
- CSS3 (Variables, Grid/Flexbox, Animations, Glassmorphism, 3D Transforms)
- Vanilla JavaScript (DOM Manipulation, Event Listeners, Validation Logic)
- Ionicons (Open source iconography)
